# 任务说明模板

贡献者可在 issue、PR 或自己的工作目录中记录跨会话任务；公共源码不要求访问维护者的实例资料。小改动无需建立任务文档。规则见 [AGENTS.md](../../AGENTS.md)。

- 写清目标、范围、不做、已定决策与验收证据；不得包含凭据、个人连接信息或运行数据。
- 交接时区分实现、合入、部署和真实验收；不把构建或接口接收当成全链完成。
- 更新已有状态，避免追加过期计划。持久结论进入对应产品/工程文档。

```markdown
# <任务名>

状态：进行中 | 等待决定 | 已完成
分支 / revision：<可复核版本>

## 目标与验收

## 范围 / 不做

## 已定决策

## 当前进度与验证证据

## 下一步 / 未决问题
```
